 Data Analysis using NumPy and Pandas
 Project Overview

This assignment focuses on learning and implementing fundamental data analysis techniques using NumPy and Pandas in Python.

The objective is to understand how to create arrays and Series, perform numerical computations, explore datasets, access and manipulate data, and perform basic data analysis operations.

 Objectives
Understand NumPy array creation and properties.
Perform mathematical operations using NumPy.
Learn array indexing and slicing.
Create and manipulate Pandas Series.
Understand DataFrame creation and exploration.
Perform data filtering, grouping, and aggregation.
Modify, add, and delete rows and columns in a DataFrame.
🛠️ Technologies Used
Python – Programming language
NumPy – Numerical computing and array operations
Pandas – Data manipulation and analysis
Jupyter Notebook – Interactive development environment

1. NumPy Array Operations

Problem Statement: Analyze daily average temperature data recorded over two weeks using NumPy.

Topics Covered:

Creating a 1D NumPy array.
Inspecting array properties:
Shape
Data type
Number of elements
Converting Celsius to Fahrenheit.
Calculating maximum, minimum, and mean temperatures.
Array indexing and slicing.
Creating a 2D NumPy array.
Extracting weekly and weekend temperatures.



2. Pandas Series

Problem Statement: Create and manipulate a Pandas Series containing student marks with custom index labels.

Topics Covered:

Creating a Pandas Series.
Assigning custom indices.
Accessing elements using integer positions.
Indexing using loc and iloc.
Boolean masking.
Filtering marks greater than 90.
Modifying Series values.
Removing Series entries.
Calculating CGPA by dividing marks by 10.


3. Pandas DataFrame

Problem Statement: Create, explore, and manipulate a transaction dataset containing product categories, regions, and transaction amounts.

Topics Covered:

A. DataFrame Creation

Creating a DataFrame using a Python dictionary.
Understanding rows and columns.

B. Data Exploration

Displaying the complete DataFrame.
Using head() and tail().
Checking DataFrame shape.
Retrieving column names and data types.
Using info().
Selecting specific columns.
Retrieving columns using iloc and loc.
Filtering rows based on conditions.
Finding value counts using value_counts().
Finding unique values using unique().
Grouping data using groupby().
Calculating average transaction amounts using mean().

C. DataFrame Manipulation

Updating transaction amounts using loc.
Adding a Discount column (10% of Amount).
Removing rows based on TransactionID.
Deleting columns using drop().
